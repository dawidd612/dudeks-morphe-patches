My collection of Android app patches for [Morphe](https://morphe.software). Each patch can be selected separately; supported versions are listed below.

## Installation

[Add this source to Morphe](https://morphe.software/add-source?github=dawidd612/dudeks-morphe-patches), or add the repository manually:

```text
https://github.com/dawidd612/dudeks-morphe-patches
```

Choose a supported app version, select the patches you want and patch a clean APK or XAPK. After a source update, rebuild the app to apply the changes.

### Mapa Turystyczna

Version **1.16.6 (153)**, XAPK. **Local Premium** changes the local feature checks used by navigation, offline map controls and ads. It is experimental and disabled by default; it does not activate Premium on your account. **Hide Premium prompts** removes the trial notification and Premium menu entry, and includes Local Premium. See [notes and testing](docs/hiking-map.md).

### AndroPods

Use version **1.5.30**, version code **86**, in XAPK format.

| Patch | What it does |
| --- | --- |
| Premium | Enables Pro features and keeps them enabled when billing refreshes. |
| Play Store Fix | Removes the startup check that asks you to install the app from Google Play. |

Both are selected by default. Play Store Fix also works without Premium. Premium alone does not remove the installation check.

### Instagram

**Keep DM scroll position** is an optional add-on for Piko's Instagram patches.
Select Piko **Add settings** in the same patching run, then find **Piko Settings > Direct Messages > Keep scroll position when replying**.
The option is enabled by default and includes Polish translations. Existing saved choices are preserved. See [implementation, compatibility and phone testing](docs/instagram-dm-scroll.md).
The release index above is generated by the release workflow. The add-on is available in the published patches bundle.

### TikTok

**Keep TikTok DM scroll position** keeps your place while reading older messages, including after ordinary sends and replies in TikTok Global **47.0.3** (`com.zhiliaoapp.musically`). Select it together with your [kveld9 patches](https://github.com/kveld9/kveld-morphe-patches) when patching a clean app. It is enabled by default; its Morphe description is in English.

**PL:** Patch zachowuje pozycję historii przy wysyłaniu dowolnych wiadomości oraz przy zwijaniu pola tekstu, cytatu i zmianie rozmiaru klawiatury. Jest domyślnie zaznaczony na liście patchy Morphe. Aby go wyłączyć, odznacz go i ponownie spatchuj aplikację. Nie dodaje panelu Piko do TikToka.

See [DEX analysis, compatibility and phone testing](docs/tiktok-dm-scroll.md).

### Gardenscapes

**Repair negative stars once** is an experimental recovery patch for the original **9.9.0 ARM64** build, selected by default in Morphe. It skips the local unofficial-install dialog. When the garden reads a negative saved star balance, the patch corrects it to **2** through the game's property setter. No level completion is needed. It preserves earned stars when repairing the spent counter, and never tops up a normal balance after spending. A v2 app-private marker records completion; an old v1 marker cannot block this repair attempt. Clearing app data or uninstalling removes the marker. Account/server restrictions are unaffected.

**PL:** Patch jest domyślnie zaznaczony i nie wymaga włączania w grze. Po aktualizacji otwórz ogród: ujemne saldo powinno zmienić się na dokładnie 2 przy odczycie licznika, bez przechodzenia kolejnego levelu. Sprawdź wydanie gwiazdki na rzeczywiste zadanie, restart i synchronizację. Nie usuwaj aktualnej instalacji ani danych. Nowa naprawa wymaga jeszcze potwierdzenia na telefonie.

See [native analysis, limitations and phone testing](docs/gardenscapes-star-repair.md).

### Android blocks overlay access

If Android displays "App was denied access" when you enable "Display over other apps", open **Settings > Apps > AndroPods > More (three dots) > Allow restricted settings**. Confirm the prompt, then return to the overlay setting and enable it.

Only allow this for an APK you trust. The restriction belongs to Android, so neither patch grants the permission or removes the system prompt. Menu names vary by device; see [Google's instructions](https://support.google.com/android/answer/12623953). If the option is missing, include your phone model and Android version in a bug report.

## Build

Requires Java 21 and access to the Morphe Gradle dependencies.

```shell
./gradlew :patches:buildAndroid --no-daemon
```

[Releases](https://github.com/dawidd612/dudeks-morphe-patches/releases) contain the `.mpp` bundle, metadata and SHA-256 checksums. GitHub Actions builds and publishes them from `main`.
